Presentation Project

The project allows the user to upload XML patent files (.zip) to a database (MySQL) through the home page, managing folders and viewing those that have already been registered. Then, through the database UI, the user can view the data in detail, while statistical analysis of the records is also provided. Select the home page to import the data.

Main Objectives of the Assignment
🎯Goals of the Project
The application aims to manage, analyze, and present data in a way that supports the thesis and automates a large part of the evaluation process.
📥 What Data Does the User Collect?
The user uploads XML data files that contain parameters or experimental results, which are stored in the database for further processing.
⚙️ What Analyses Are Performed?
The system performs data cleaning, statistical processing, value grouping, creation of analysis scenarios, and evaluation of data quality.
🧠 What Technologies Are Used?
The platform uses Python and Flask for data processing and management, HTML/CSS/JavaScript for the interactive environment, an SQL database for storage, and libraries such as Pandas, NumPy, and Chart.js for statistical analysis and visualization creation.
